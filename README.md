# Gestion de aldeanos en Minecraft

## Problema a resolver:
Se tiene una cantidad no manejable de aldeanos en cierta zona de un mundo de Minecraft, los jugadores tienen dificultades para organizar, registrar y administrar
esta misma por lo tanto se busca facilitar y llevar a cabo un sistema que permita la gestion eficiente de este recurso digital.

## Usuarios del sistema
| Usuarios | Tarea desempeñada  |
| -------- | -------------------|
| Jugador NOOB | Hace uso del sistema de gestion |
| Jugador PRO | Ingresar aldeanos al sistema |
| Aldeano HACKER | Borra el registro de otros aldeanos |
